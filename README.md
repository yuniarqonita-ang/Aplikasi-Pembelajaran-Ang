# 🤖 Akademi IT, Koding, & TOEFL iBT Kodi

Selamat datang di **Akademi IT, Koding, & TOEFL iBT Kodi**! 🎉  
Aplikasi pembelajaran interaktif berbasis proyek (*Project-Based Learning* / PBL) yang dirancang khusus untuk pemula, lulusan non-IT, persiapan tes teknis kerja IT Support/Software, serta **persiapan tes TOEFL iBT untuk beasiswa S2 luar negeri (LPDP, Chevening, Fulbright, AAS, MEXT)**!

Aplikasi ini menggunakan **bahasa bayi (analogi sehari-hari yang super ramah tanpa rumus dan istilah rumit)**, simulator suara interaktif, serta **dapat di-download / dipasang langsung di HP layaknya aplikasi resmi**!

---

## 🌟 Fitur Unggulan Utama

### 1. 🎓 Modul Spesial TOEFL iBT Beasiswa S2 (Building Skills Book Edition)
Disusun berdasarkan buku acuan resmi: **`Building Skills for the TOEFL iBT [2nd Edition]` (Compass Publishing)**:
- **Skill 1: Vocabulary in Context**:
  - Bedah kosakata akademik tingkat lanjut (*ubiquitous, diminish, pivotal, harness, resilient, plausible*) lengkap dengan trik analogi bahasa bayi Kodi.
- **Skill 2: Sentence Simplification**:
  - Trik menjinakkan monster kalimat panjang akademik (AI *Opacity / Black Box Dilemma*, otomatisasi industri, *urban heat island*) tanpa kehilangan informasi esensial.
- **Skill 3: Fact & Negative Fact**:
  - Trik memindai fakta (*scanning*) dan mendeteksi jawaban palsu (*NOT / EXCEPT* questions) pada teks sains geotermal dan komunikasi lebah (*waggle dance*).
- **Skill 4: Inference Questions**:
  - Logika detektif ilmiah untuk membaca kesimpulan tersirat pada eksperimen memori otak (*working memory limits*) dan es bawah permukaan Mars.
- **Skill 5: Text Insertion [■]**:
  - Teka-teki gerbong kereta (*jigsaw puzzle*) untuk menemukan posisi paling pas menyisipkan kalimat transisi akademik.
- **Skill 6: Speaking iBT Simulator**:
  - **Timer Resmi Ujian**: Hitung mundur Waktu Persiapan (15 detik) dan Waktu Berbicara (45 detik).
  - **Evaluasi Suara Mikrofon**: Penilaian akurasi pelafalan kata per kata secara langsung.
  - **Naskah Model Jawaban Juara (Band 26-30)**: Dilengkapi audio native (Normal & Slow) serta formula 4 langkah menjawab speaking iBT.

---

### 2. 🗄️ Studio Tes Tertulis SQL & Output Koding (Khas Tes Kerja IT Software)
Dirancang khusus berdasarkan soal-soal tes tertulis yang sering ditanyakan di perusahaan industri teknologi & manufaktur modern:
- **Kueri SQL Berbasis Tabel Nyata**:
  - Tabel `Employees` (Daftar Karyawan, Gaji, Divisi IT/Finance/Produksi).
  - Tabel `ShoeProduction` (Data Produksi Sepatu Pabrik, Model, Pasang Sepatu, Status QC).
- **Editor Kueri Interaktif**:
  - Belajar kueri `SELECT`, `WHERE`, `ORDER BY DESC`, `COUNT(*)`, dan agregasi data dengan visual tabel responsif instan.
- **Tes Tebak Output Kode (Code Output Prediction Drill)**:
  - Soal-soal tebak hasil eksekusi koding dalam bahasa Inggris (*loop*, *array*, percabangan *if-else*, fungsi agregasi SQL) yang dilengkapi trik pemecahan masalah bahasa bayi.

---

### 3. 🗣️ Studio Bahasa Inggris & Speaking Interaktif (Wawancara Kerja & Marathon Grammar)
- **Wawancara Kerja Profesional Berbobot**:
  - Simulasi tanya-jawab wawancara kerja teknis IT untuk kandidat berlatar belakang matematika & pendidikan dengan sertifikasi desain grafis BNSP.
  - Dengarkan pelafalan penutur asli (Normal & Slow) dan latih suara lewat mikrofon dengan penilaian instan.
- **Game Huruf Hilang & Kosakata (Missing Letters Puzzle)**:
  - 25 puzzle kata kunci IT, tata bahasa, dan kosakata beasiswa (*DATABASE, ANALYSIS, HYPOTHESIS, SUBJUNCTIVE, INFERENCE, RESILIENT, COMPREHENSIVE*).
- **Marathon Soal TOEFL ITP & Cambridge IELTS**:
  - 25 kisi-kisi tata bahasa terlengkap (*Tenses, Subject-Verb Agreement, Passive Voice, Conditionals, Relative Clauses, Inversion, Subjunctive Mood, Reduced Clauses*).

---

### 4. 🗺️ 5 Misi Petualangan IT Support & Logika Koding (PBL)
- **Level 1: Anatomi Komputer (Dapur Restoran)** 🖥️ — CPU (Koki), RAM (Meja Kerja), SSD (Kulkas File), PSU (Jantung Listrik).
- **Level 2: Mantra Gaib Terminal (CLI IT Support)** 📟 — Perintah sakti `ipconfig`, `ping 8.8.8.8`, `mkdir`, `cls`.
- **Level 3: Kantor Pos Jaringan (Networking Dasar)** 🌐 — IP Address (Nomor Rumah), DNS (Buku Kontak HP), Router (Polisi Lalu Lintas).
- **Level 4: Resep Rahasia Koding (Logika Robot)** 🧠 — Toples Variabel, Logika IF-ELSE pendingin server kantor.
- **Level 5: Meja Bantuan IT Support (Tiket Keluhan Nyata)** 🏆 — Printer macet (*paper jam*), WiFi tanda seru kuning ⚠️ (*renew IP*), dan otomatisasi backup data 1-klik.

## 🚀 Cara Menjalankan Aplikasi di Komputer

### Cara 1: Peluncur 1-Klik (Windows)
- Cukup klik dua kali berkas **`Buka_Aplikasi.bat`** di dalam folder ini!
- Aplikasi akan otomatis terbuka di browser favoritmu (Google Chrome, Microsoft Edge, dll).

### Cara 2: Buka Langsung Berkas HTML
- Klik kanan berkas **`index.html`** -> Pilih **Open with** -> **Google Chrome** atau **Microsoft Edge**.

---

## 📲 Cara Memasang (Download) Aplikasi di HP

1. Buka tautan repositori GitHub Pages atau buka berkas web ini di browser **Google Chrome** di HP kamu.
2. Ketuk tombol **"📲 Pasang di HP"** di bagian atas aplikasi, ATAU ketuk menu titik tiga (**⋮**) di pojok kanan atas browser.
3. Pilih **"Tambahkan ke Layar Utama"** (*Add to Home Screen*) atau **"Install Aplikasi"**.
4. Ikon robot **Kodi IT** akan langsung muncul di menu aplikasi HP kamu dan siap dimainkan kapan saja secara offline!
