# 🤖 Akademi IT & Koding Kodi

Selamat datang di **Akademi IT & Koding Kodi**! 🎉  
Aplikasi pembelajaran interaktif berbasis proyek (*Project-Based Learning* / PBL) yang dirancang khusus untuk pemula, lulusan non-IT, serta persiapan tes tertulis dan wawancara kerja teknis (posisi IT Software & IT Support di perusahaan multinasional dan industri manufaktur)!

Aplikasi ini menggunakan **bahasa bayi (analogi sehari-hari yang super ramah tanpa rumus dan istilah yang bikin pusing)**, dilengkapi simulator suara interaktif, serta **dapat di-download / dipasang langsung di HP layaknya aplikasi resmi**!

---

## 🌟 Fitur Unggulan Terbaru

### 1. 🗄️ Studio Tes Tertulis SQL & Output Koding (Khas Tes Kerja IT Software)
Dirancang khusus berdasarkan soal-soal tes tertulis yang sering ditanyakan di perusahaan industri (seperti kualifikasi *C#, JS, MSSQL* di industri manufaktur & teknologi):
- **Kueri SQL Berbasis Tabel Nyata**:
  - Tabel `Employees` (Daftar Karyawan, Gaji, Divisi IT/Finance/Produksi)
  - Tabel `ShoeProduction` (Data Produksi Sepatu Pabrik, Model, Pasang Sepatu, Status QC)
- **Editor Kueri Interaktif**:
  - Belajar kueri `SELECT`, `WHERE`, `ORDER BY DESC`, `COUNT(*)`, dan filter data dengan tombol balok instan dan tampilan hasil tabel langsung!
- **Tes Tebak Output Kode (Code Output Prediction Drill)**:
  - Soal-soal tebak hasil eksekusi koding dalam bahasa Inggris (perulangan *loop*, manipulasi *array*, kondisi *if-else*, fungsi agregasi SQL) yang dilengkapi **"🍼 Penjelasan Bahasa Bayi"** yang super gamblang.

---

### 2. 🗣️ Studio Bahasa Inggris Interaktif (Speaking, Listening, & TOEFL/IELTS)
Biar kamu percaya diri menghadapi kualifikasi *"Fluent in English both speaking and writing"*:
- **Fitur Suara Listening (Text-to-Speech)**:
  - Dengarkan pelafalan asli penutur bahasa Inggris dengan tombol 🔊 (Pilihan kecepatan Normal dan Lambat/Slow).
- **Fitur Bicara & Koreksi Suara (Speech Recognition)**:
  - Tekan tombol 🎙️ **"Mulai Bicara"**, ucapkan kalimat jawabanmu lewat mikrofon di PC atau HP.
  - Sistem akan langsung **menilai akurasi pelafalanmu (0-100%)** dan memeriksa kata per kata (warna hijau = pelafalan jelas, merah = perlu dilatih lagi).
- **Simulasi Wawancara Kerja IT (IT Job Interview)**:
  - Latihan menjawab pertanyaan seputar *Self Introduction*, *Database/SQL*, *Troubleshooting Jaringan*, dan *Teamwork*.
- **Latihan Soal Structure TOEFL ITP & IELTS**:
  - Latihan tata bahasa (*Subject-Verb Agreement*, *Passive Voice*, *Relative Pronoun*, *Conditionals*) lengkap dengan rumus logika bahasa bayi.

---

### 3. 🗺️ 5 Misi Petualangan IT Support & Logika Koding (PBL)
- **Level 1: Anatomi Komputer (Dapur Restoran)** 🖥️ — CPU (Koki), RAM (Meja Kerja), SSD (Kulkas File), PSU (Jantung Listrik).
- **Level 2: Mantra Gaib Terminal (CLI IT Support)** 📟 — `ipconfig`, `ping 8.8.8.8`, `mkdir`, `cls`.
- **Level 3: Kantor Pos Jaringan (Networking Dasar)** 🌐 — IP Address (Nomor Rumah), DNS (Buku Kontak HP), Router (Polisi Lalu Lintas).
- **Level 4: Resep Rahasia Koding (Logika Robot)** 🧠 — Toples Variabel, Logika IF-ELSE pendingin server kantor.
- **Level 5: Meja Bantuan IT Support (Tiket Keluhan Nyata)** 🏆 — Printer macet (*paper jam*), WiFi tanda seru kuning ⚠️ (*renew IP*), dan otomatisasi backup 1-klik Pak Bos.

### 4. 📱 Bisa Dipasang / Didownload di Layar Utama HP (PWA)
Aplikasi ini sudah berstandar **Progressive Web App (PWA)**:
- Bisa dibuka dan di-install di smartphone (Android / iOS).
- Tampilan 100% responsif dan nyaman digunakan lewat layar sentuh HP.
- Mendukung mikrofon HP untuk latihan *English Speaking* di mana saja!

## 🚀 Cara Menjalankan Aplikasi di Komputer

### Cara 1: Peluncur 1-Klik (Windows)
- Cukup klik dua kali berkas **`Buka_Aplikasi.bat`** di dalam folder ini!
- Aplikasi akan otomatis terbuka di browser favoritmu (Google Chrome, Microsoft Edge, dll).

### Cara 2: Buka Langsung Berkas HTML
- Klik kanan berkas **`index.html`** -> Pilih **Open with** -> **Google Chrome** atau **Microsoft Edge**.

---

## 📲 Cara Memasang (Download) Aplikasi di HP

1. Buka tautan repositori GitHub Pages atau buka berkas web ini di browser **Google Chrome** di HP kamu.
2. Ketuk tombol **"📲 Pasang di HP"** di bagian atas aplikasi, ATAU ketuk tombol titik tiga (**⋮**) di pojok kanan atas browser Google Chrome.
3. Pilih **"Tambahkan ke Layar Utama"** (*Add to Home Screen*) atau **"Install Aplikasi"**.
4. Ikon robot **Kodi IT** akan langsung muncul di menu aplikasi HP kamu dan siap dimainkan kapan saja!
